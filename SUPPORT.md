# Getting help

For a bug or feature request, use the relevant product repository's issue forms. Include the version and enough detail to reproduce the problem. Please search existing issues first.

For CloseYourIt information and current availability, visit https://closeyour.it.

For collaboration or commercial enquiries, use https://www.bussolarialessio.me/contact.

For a suspected vulnerability, follow [SECURITY.md](SECURITY.md). Public issues are not a private support channel, and community support does not include a guaranteed response time.
