# Small studio. Useful software.

**Independent tools for people who build and run software.**

BussoLabs is the software studio of [Alessio Bussolari](https://www.bussolarialessio.me), based on Italy's Adriatic coast. We build practical products from the problems we encounter running our own projects.

Our next chapter is open source: software you can inspect, run on your own infrastructure and help improve.

[Explore CloseYourIt](https://closeyour.it) · [Meet the maker](https://www.bussolarialessio.me)

## First up: CloseYourIt

### From an error to the work that fixes it.

Errors, tickets, uptime, performance and logs in one workspace. Keep the evidence next to the issue, so you can move from noticing a problem to understanding what needs to change.

**Open-source release in preparation.** CloseYourIt is moving toward a self-hosted distribution, with optional AI integrations. Public source, installation instructions and contribution links will appear here when the release is ready.

[Visit CloseYourIt](https://closeyour.it)

## What guides our products

- **Useful before elaborate.** Start with a real problem and a clear path through it.
- **Control stays with you.** Self-hosting and inspectable source are the direction of our open-source releases.
- **Clear boundaries.** Each product will explain its license, what runs locally and which optional services connect elsewhere.
